
# Given business requirements, identify when it’s appropriate to use Prompt Builder.

## Introduction
Prompt Builder is a tool that allows users to create detailed prompt templates that instruct large language models (LLMs) to produce AI-generated responses. A prompt template consists of a prompt that utilizes various elements like ingredients, guidelines, and grounding.Prompt Builder offers several types of reusable prompt templates, such as Sales Email, Field Generation, Record Summary, and Flex, that can be configured to meet specific business needs. The Prompt Template Workspace allows users to draft and test these prompt templates. The Draft with Einstein button allows users to draft emails using a sales email prompt template. Users can click an icon next to a dynamic form field to use a field generation prompt template and populate the field with AI-generated text. In addition, invocable actions and flows provide seamless integration of prompt templates with workflows

### Prompt
A prompt is a set of detailed instructions sent to a large language model (LLM) to produce a response. It utilizes various ingredients, guidelines, and grounding. 
### Prompt Template
A prompt template is a reusable, detailed prompt that can be created and managed in Prompt Builder. 
### Prompt Template Types
Prompt Builder can be used to create several types of prompt templates, such as Contextual Service Replies, Field Generation, Flex, Grounded Service Replies, Knowledge Answers, Record Summary, and Sales Email.
### Prompt Template Workspace
The Prompt Template Workspace allows drafting a prompt and grounding it with data using merge fields. The resolved prompt and the generated response can be previewed. 
### Using Prompt Templates
How a prompt template is used depends on its type. It can also be invoked through an invocable action or by using the Connect REST API or Connect in Apex.
### Prompt Templates & Flows
A Template-Triggered Prompt Flow can be used to add instructions to a prompt template. The Prompt Template flow action can be used in a flow to invoke a prompt template.

## Prompt Builder
### Prompts
A prompt is a set of detailed instructions sent to a large language model (LLM) to produce a response. The quality and relevance of the response is determined by prompt design.
#### PROMPT DESIGN
Prompt design refers to the process of creating prompts that improve the quality and accuracy of the responses generated by models.
#### PROMPT INSTRUCTIONS
Prompt instructions are natural language instructions that describe a specific task for the LLM. For example, “Write a product description that is no longer than 100 words.”
#### PROMPT INGREDIENTS
Some key ingredients that should be included in an effective prompt include participants, setting, goal, relationships, and data. 
#### PROMPT GUIDELINES
A prompt can also include additional information such as limits, language, style, and tone guidelines that must be followed by the LLM.
#### PROMPT TEMPLATE
A prompt template is a reusable, detailed prompt that can be created and managed in Prompt Builder. It is driven by the use case and includes information that helps the LLM generate a high-quality response. 
#### GROUNDING
A prompt should be grounded in data that is relevant to the request to ensure high-quality responses. Grounding adds context and personalization to prompts.

### Prompt Builder
Prompt Builder can be used to create, test, revise, customize, and manage prompt templates.
#### ENABLING PROMPT BUILDER
Users can be allowed to use Prompt Builder by setting up Einstein Generative AI and assigning the correct permission set to users.
#### PERMISSION SETS
The Prompt Template Manager permission set allows users to create and manage prompt templates in Prompt Builder. The Prompt Template User permission set allows users to access and run prompt templates.
#### USING PROMPT BUILDER
Users can create prompt templates by accessing the Prompt Builder page in Setup and clicking the New Prompt Template button. The page displays all the standard and custom prompt templates in the org

#### PROMPT TEMPLATE TYPES
Creating a prompt template requires selecting a Prompt Template Type that matches the use case. The available types include Campaign Brief, Case Summary, Contextual Service Replies, Contract Analysis, Field Generation, Flex, Grounded Service Replies, Generate case description, Generate case subject, Knowledge Answers, Sales Emails, Sales Pitch Coaching, Security Risk Analysis, Record Prioritization, Record Summary, Work Summary, etc.
#### STANDARD TEMPLATES
Salesforce provides various standard templates that consist of detailed, thoughtfully worded prompts that represent a variety of common use cases for different prompt template types.
#### CUSTOM PROMPT TEMPLATES
Custom templates can be created from scratch or a standard template. A standard template can be copied using the Save as a New Template button, customized, and then saved as a custom template.
#### NEW TEMPLATE OPTIONS
When creating a new custom prompt template, its Prompt Template Type, Prompt Template Name, and Template Description can be specified. Other fields depend on the selected prompt template type.

### Prompt Template Types
One of several prompt template types can be selected when creating a new prompt template.
