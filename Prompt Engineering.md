
# Given business requirements, identify when it’s appropriate to use Prompt Builder.

## Introduction
Prompt Builder is a tool that allows users to create detailed prompt templates that instruct large language models (LLMs) to produce AI-generated responses. A prompt template consists of a prompt that utilizes various elements like ingredients, guidelines, and grounding.Prompt Builder offers several types of reusable prompt templates, such as Sales Email, Field Generation, Record Summary, and Flex, that can be configured to meet specific business needs. The Prompt Template Workspace allows users to draft and test these prompt templates. The Draft with Einstein button allows users to draft emails using a sales email prompt template. Users can click an icon next to a dynamic form field to use a field generation prompt template and populate the field with AI-generated text. In addition, invocable actions and flows provide seamless integration of prompt templates with workflows

### Prompt
A prompt is a set of detailed instructions sent to a large language model (LLM) to produce a response. It utilizes various ingredients, guidelines, and grounding. 
### Prompt Template
A prompt template is a reusable, detailed prompt that can be created and managed in Prompt Builder. 
### Prompt Template Types
Prompt Builder can be used to create several types of prompt templates, such as Contextual Service Replies, Field Generation, Flex, Grounded Service Replies, Knowledge Answers, Record Summary, and Sales Email.
### Prompt Template Workspace
The Prompt Template Workspace allows drafting a prompt and grounding it with data using merge fields. The resolved prompt and the generated response can be previewed. 
### Using Prompt Templates
How a prompt template is used depends on its type. It can also be invoked through an invocable action or by using the Connect REST API or Connect in Apex.
### Prompt Templates & Flows
A Template-Triggered Prompt Flow can be used to add instructions to a prompt template. The Prompt Template flow action can be used in a flow to invoke a prompt template.

## Prompt Builder
### Prompts
A prompt is a set of detailed instructions sent to a large language model (LLM) to produce a response. The quality and relevance of the response is determined by prompt design.
#### PROMPT DESIGN
Prompt design refers to the process of creating prompts that improve the quality and accuracy of the responses generated by models.
#### PROMPT INSTRUCTIONS
Prompt instructions are natural language instructions that describe a specific task for the LLM. For example, “Write a product description that is no longer than 100 words.”
#### PROMPT INGREDIENTS
Some key ingredients that should be included in an effective prompt include participants, setting, goal, relationships, and data. 
#### PROMPT GUIDELINES
A prompt can also include additional information such as limits, language, style, and tone guidelines that must be followed by the LLM.
#### PROMPT TEMPLATE
A prompt template is a reusable, detailed prompt that can be created and managed in Prompt Builder. It is driven by the use case and includes information that helps the LLM generate a high-quality response. 
#### GROUNDING
A prompt should be grounded in data that is relevant to the request to ensure high-quality responses. Grounding adds context and personalization to prompts.

### Prompt Builder
Prompt Builder can be used to create, test, revise, customize, and manage prompt templates.
#### ENABLING PROMPT BUILDER
Users can be allowed to use Prompt Builder by setting up Einstein Generative AI and assigning the correct permission set to users.
#### PERMISSION SETS
The Prompt Template Manager permission set allows users to create and manage prompt templates in Prompt Builder. The Prompt Template User permission set allows users to access and run prompt templates.
#### USING PROMPT BUILDER
Users can create prompt templates by accessing the Prompt Builder page in Setup and clicking the New Prompt Template button. The page displays all the standard and custom prompt templates in the org

Prompt Builder can be accessed by navigating to Prompt Builder in Salesforce Setup

#### PROMPT TEMPLATE TYPES
Creating a prompt template requires selecting a Prompt Template Type that matches the use case. The available types include Campaign Brief, Case Summary, Contextual Service Replies, Contract Analysis, Field Generation, Flex, Grounded Service Replies, Generate case description, Generate case subject, Knowledge Answers, Sales Emails, Sales Pitch Coaching, Security Risk Analysis, Record Prioritization, Record Summary, Work Summary, etc.
#### STANDARD TEMPLATES
Salesforce provides various standard templates that consist of detailed, thoughtfully worded prompts that represent a variety of common use cases for different prompt template types.
#### CUSTOM PROMPT TEMPLATES
Custom templates can be created from scratch or a standard template. A standard template can be copied using the Save as a New Template button, customized, and then saved as a custom template.
#### NEW TEMPLATE OPTIONS
When creating a new custom prompt template, its Prompt Template Type, Prompt Template Name, and Template Description can be specified. Other fields depend on the selected prompt template type.
#### PROMPT TEMPLATE WORKSPACE
The Prompt Template Workspace allows drafting a prompt and grounding it with data using merge fields. The Insert Resource button can be used to add a merge field.
#### PREVIEW
The Preview button can be clicked to preview the resolved prompt and the generated response. The Resolved Prompt section displays the prompt with the grounding data that was selected in the Preview Settings. The Generated Response section displays the grounded response generated by the LLM.
#### TESTING
After making changes, a prompt template can be tested by selecting record(s) and clicking the Save & Preview button to view the resolved template and the response generated for the selected record(s).
#### TEMPLATE SETTINGS
The Template Settings icon can be clicked to display the Template Details section, which allows selecting the large language model (LLM). It also allows selecting the Response Format and the Response Language.

### Using Prompt Templates
Users can apply prompt templates to draft emails, generate summaries, complete text form fields, and perform other unique tasks.
#### SALES EMAIL
Users can draft a personalized email using a custom sales email prompt template by clicking the Draft with Einstein button in the Lightning Experience email composer.
#### FLEX TEMPLATE
Flex prompt templates are specific to the use cases, so they can be called wherever they are needed. For example, a flex prompt template can be called with an invocable action using REST API.
#### FIELD GENERATION
Users can click an icon next to a dynamic form field that is associated with a field generation prompt template to populate it with an AI-generated description or summary.
#### INTEGRATION
A prompt template can be called through an invocable action anywhere on the Salesforce Platform or by using the Connect REST API or Connect in Apex.

### Prompt Templates & Flows
Prompt templates can be used with flows created in Flow Builder.
#### FLOW
A Template-Triggered Prompt Flowcan be created to provide data to a prompt template using the Add Prompt Instructions flow element. A flow merge field can be added to the template to trigger the flow.
#### FLOW ACTION
A Prompt Template flow action can be added to a flow to generate a prompt response based on a specific prompt template and inputs. The prompt template must have an active version.

### Template-Triggered Prompt Flows
A template-triggered prompt flow can be created to perform dynamic logic and actions to generate output text that’s merged into the associated prompt template’s resolution.
A template-triggered prompt flow must be created in Flow Builder to make its flow merge field available for adding to a prompt template. The flow sends its prompt instructions to the associated prompt template. 
For example, this type of flow can be used to retrieve new cases related to a particular account and send their details to a prompt template using a flow merge field.

### Prompt Template Action
A Prompt Template action can be added to a flow to generate a response using a prompt template.

## Scenarios & Solutions
### Scenario 1
Cosmic Electronics is exploring public generative AI models to assist its sales and service teams. While they have experience crafting prompts to extract information effectively, users find it challenging and time-consuming to write prompts for each interaction manually. For instance, a support manager must create a new prompt every time a new bulletin post about product updates needs to be generated. The company seeks the assistance of an AI specialist to standardize prompts to save time and maintain response consistency
### Solution 1
The company can use Einstein Prompt Builder to address the challenges. Prompt Builder enables the creation of reusable prompt templates for large language models (LLMs). Prompt templates contain standardized prompts for quick and consistent AI-generated responses. They can be integrated with workflows to enhance the efficiency of the company’s sales and service teams.

### Scenario 2
Cosmic Computers wants to draft a sales proposal using generative AI. The proposal should use data from multiple unrelated standard and custom objects. An AI specialist is required to recommend an appropriate solution for this requirement.
### Solution 2
A Flex prompt template can be created in Prompt Builder to meet the requirement. It is suitable for any unique business case that is not covered by the other template types, such as creating a sales proposal. Resourcesfor standard and custom objects as inputs can be added to the template. It can be called through an invocable action anywhere on the Salesforce platform or by using the Connect REST API or Connect in Apex.

### Scenario 3
The sales team at Cosmic Hotels wants to create personalized guest summaries that capture interests and activity preferences from guest profiles. These summaries will help them tailor recommendations for each guest and should be easily accessible only on the contact record page.
### Solution 3
The team should use Prompt Builder to create a Field Generation prompt template. It can automatically populate a dynamic form field on the contact record page. Instructions can be added to the prompt template to create a summary based on a guest’s interests and activity preferences. A user can click an icon next to the field on the contact record page to generate the summary.

### Scenario 4
Cosmic Hardware aims to develop a custom user experience within Salesforce that allows users to input a sales order number. Once entered, the system should automatically generate and display a summary of the order’s header and details using a predefined prompt template.
### Solution 4
A screen flow can be created to collect the sales order number from users. The flow should use the standard Prompt Template flow action to invoke a custom prompt template that generates a detailed sales order summary. A screen element can be added to the flow to display the summary to a user who runs the flow.

### Scenario 5
The leadership team at Cosmic Furniture wants to enhance customer interactions by automatically populating a dynamic form field with a description generated by a large language model (LLM). The description should be easy to review and edit to maintain the company's AI strategy of keeping a human in the loop for oversight and validation.
### Solution 5
A Field Generation prompt template can be created for the requirement. It can use AI to generate a description for a dynamic form field. Users can review, modify, and finalize the text before engaging with customers, ensuring human oversight and validation.
