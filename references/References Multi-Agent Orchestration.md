# Multi-Agent Orchestration

Build a collaborative AI agent team that works together to solve complex problems faster. With intelligent task routing, you can ensure the best-fit agent provides the best possible response, every time.

## Deliver one seamless conversation, powered by a team of agents.

Eliminate friction with a single, intelligent point of contact for your customers. Create a primary agent to route tasks to a team of specialized agents, so users get the right answer from the right agent without ever losing context.

## Coordinate tasks across your agent teams.

The primary agent serves as the single, intelligent entry point for all user interactions. It analyzes the initial query to understand intent, then seamlessly routes the task to the best-specialized agent for the job for a consistent and context-aware experience.

Secondary agents work behind the scenes to handle tasks the primary agent delegates. They leverage deep contextual knowledge for more accurate, relevant responses. Grounded with specific data and equipped with a library of available actions, each specialist agent resolves the query and passes the final answer back to the primary agent to share with the user.

[Agentforce](https://www.salesforce.com/agentforce/)’s Atlas Reasoning Engine powers task orchestration. It reviews each agent’s description, instructions, and available actions to determine which specialist agent is best equipped for the job and intelligently routes the task.

## Multi-Agent Orchestration FAQ

### What is Multi-Agent Orchestration?

Multi-Agent Orchestration allows you to build a team of specialized [AI agents](https://www.salesforce.com/agentforce/ai-agents/) that work collaboratively to solve complex problems. A primary agent serves as a single point of contact, routing tasks to the best-fit specialist agent for a seamless conversation.

### How does multi-agent orchestration provide a seamless user experience?

It eliminates user friction by having a single, intelligent primary agent interact with the customer. Behind the scenes, this agent handles all the complexity, routing the query to a team of specialists without the user ever losing context or having to repeat themselves.

### Can Agentforce connect to third-party agents?

Yes. With Agent2Agent (A2A) support, you can connect Agentforce to your entire AI ecosystem. This open collaboration allows a primary agent to securely connect and delegate tasks to third-party agents, creating a true [agentic enterprise](https://www.salesforce.com/agentforce/agentic-enterprise/).

### How do you ensure governance and security with a multi-agent team?

Agentforce Observability is integrated to maintain complete oversight. It provides tools to monitor the performance of your entire agent team, trace interactions between agents, and enforce security policies across the system, ensuring secure innovation.
